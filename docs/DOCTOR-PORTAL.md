# 医生管理与医生后台

管理端“医生管理”与“系统管理”同级。管理员可见“医生审核”“医生账号”；医生使用同一个后台登录页，只可见获授权的“接诊工作台”“我的问诊”“我的收入”。原问诊管理地址自动跳转到医生审核。

## 开通与使用

1. 医生先在小程序“我的 → 医生工作台”提交资质；管理员进入“医生管理 → 医生审核”核验并通过。
2. 管理员进入“医生管理 → 医生账号”，为已通过的医生点击“开通后台账号”，设置登录名和初始密码。密码至少8位、最多72字节，使用现有 BCrypt 密码编码器。没有默认医生账号或通用初始密码。
3. 后台账号与小程序医生身份固定一对一绑定；小程序和后台的登录凭据不同。医生用管理员设置的账号密码登录后台，处理的是同一个医生的小程序问诊记录及沙箱钱包收入。
4. 医生先在小程序开通钱包，然后在后台接诊工作台选择求助、确认接诊。在“我的问诊”中填写评估、用药建议和复查建议，确认出具后不能修改。患者仍在小程序支付1元查看完整问诊单，费用进入该医生的沙箱钱包。
5. 管理员可在“医生账号”启停账号或重置密码。停用后台账号与停用医生资质均会阻止后续医生业务访问，资质审核状态和后台账号状态分别展示。

## 功能与菜单授权

“医生账号 → 医生功能权限”配置统一的 doctor 角色，勾选接诊工作台、我的问诊、我的收入。未勾选的功能不可打开；全部关闭时显示暂无可用功能。保存后医生会话失效，需要重新登录。管理员当前会话不因此退出。

该入口与“系统管理 → 角色管理/菜单管理”共用真实若依数据：

| 菜单 | 权限标识 | 可用身份 |
| --- | --- | --- |
| 医生审核 | `doctor:review:manage` | 管理员 |
| 医生账号 | `doctor:account:manage` | 管理员 |
| 接诊工作台 | `doctor:workbench:view` | 医生 |
| 我的问诊、接诊及出单 | `doctor:consultation:manage` | 医生 |
| 我的收入 | `doctor:income:view` | 医生 |

系统角色管理可以调整权限标识，菜单管理可以隐藏或停用菜单。隐藏影响菜单展示，停用或撤销角色授权同时撤销对应权限。若需不同医生使用不同权限组合，可先精简基础 doctor 角色，再在系统角色管理创建附加角色，并在系统用户管理给指定医生账号分配；保留 doctor 身份。可授予的医生业务权限限上述三个医生功能。

医生绑定不会因修改后台角色而消失。即使误加运营或超级管理员权限，绑定医生的后台仍被限制在医生业务接口，无法访问原有的用户管理、社区管理、系统管理、后台提醒等接口。没有绑定或没有通过资质审核，不能读取患者健康详情或收入。

## 实现位置

- `doctor/service/DoctorRealmService.java`：医生身份边界及权限范围。
- `auth/security/OpsSessionAuthFilter.java`：每次后台请求重新检查身份和权限，阻止医生访问原管理员接口。
- `auth/service/RuoYiAuthorizationService.java`：真实登录角色、权限和菜单信息。
- `doctor/service/DoctorPortalService.java`：开通账号、固定绑定、授权、本人身份解析和收入查询。
- `doctor/controller/DoctorAccountController.java`、`DoctorPortalController.java`：管理员与医生接口，分别校验角色和具体权限。
- `resources/com/threadfit/glucopilot/doctor/mapper/DoctorPortalMapper.xml`：账号绑定和本人收入 SQL。
- `db/migration/V68__doctor_admin_portal.sql`：绑定表、医生角色及菜单初始化，不创建用户或密码。
- 管理端 `src/views/doctors/`、`src/utils/doctor-access.ts`：医生页面、受控入口和安全默认跳转。审核页仍在 `src/views/users/ConsultationManagementView.vue`。

Java路径相对 `glucopilot-business/src/main/java/com/threadfit/glucopilot/`，资源路径相对 `glucopilot-business/src/main/`。

## 生效与验证

本机数据库已备份后升级到 V68，需重建、重启 IDEA 后端，刷新并重新登录管理端。小程序没有本轮前端修改，无需再次编译。

自动测试覆盖医生角色/固定绑定/误授权隔离、实际安全过滤器和方法权限、撤销功能后禁止调用接口、资质和后台停用、收入本人范围、医生账号开通及角色菜单更新后注销医生会话。页面使用隔离浏览器及本地拦截的界面样例验证，不向数据库添加演示医生、问诊、密码或资金。
