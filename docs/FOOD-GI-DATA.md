# 食品GI参考数据

2026-11-09核对。GI统一使用葡萄糖为100的标尺。数值来自食物试验或文献汇总，是对应食物形态的参考数据，不是本系统对某张照片、某批食品或某个用户的实测结果。品种、成熟度和加工方式不同，GI可能不同；GI也不等于一份食物的升糖量。

## 保留为空的数据

- 鸡胸肉、鸡蛋、瘦猪肉、矿泉水等缺乏可用于标准GI试验的碳水；多数低碳水蔬菜、部分豆制品和坚果也不应编造GI。保留NULL不等于GI为0。依据：[悉尼大学GI数据库说明](https://mail.glycemicindex.com/foodSearch.php)。
- 燕麦未明确颗粒/压片/即食形态，面条未区分干鲜及做法，酸奶和豆浆未明确配方、加工及含糖情况，苏打饼干未明确品牌；现有名称不足以匹配具体试验食品，因此暂不赋值。
- 小笼包、炒饭、火腿肠等混合或加工食品受配方影响，紫皮黄心红薯、土豆块未说明具体烹调方式；不套用原料或其他品种的数值。

## 写入与同步

- V54仅在食品名称精确匹配、未删除且gi_value为NULL时填入；已有GI、食品图片、分类、热量、碳水及审核来源保持不变。
- 数据更新后，在同一事务内增加食品缓存版本；用户端和管理端继续读取同一张food_nutrition表及gi_value字段。
- GI逐项来源保存在本说明与迁移注释中。nutrition_source描述整条营养数据的原有来源，本次不把它改成GI文献来源，也不将AI估算冒充实验测定。
- 本地执行前备份食品表及缓存版本表；回退SQL仅撤销本次新增的GI，并检查更新后的记录时间，避免覆盖后续人工编辑。
- 组员可随代码获取V54，由Flyway在其数据库执行。迁移不创建新食品，也不修改V1至V53的历史脚本。
