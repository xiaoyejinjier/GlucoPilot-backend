# 视频静态封面

“我的文章”与草稿列表通过受鉴权保护的JPEG接口显示原视频首帧，不下载/播放整段视频。原视频仍保存在原对象存储桶，不更改媒体记录或数据库表；内存缓存清空后自动重新提取。封面与原视频执行相同阅读权限检查，客户端切换账号、页面隐藏或卸载时清理临时图。

## 运行条件

- 后端运行环境安装FFmpeg，并确保运行账号能执行和使用系统临时目录；不需要ffprobe或Python。
- Dockerfile运行镜像已安装发行版FFmpeg，默认命令为`ffmpeg`。
- IDEA/普通Java启动可在工作区私密`.env`中设置`FFMPEG_PATH`为可执行文件绝对路径；Windows路径使用`/`。重启后端加载环境变量。不将可执行文件或私密配置提交仓库。
- FFmpeg安装来源：[官方下载安装说明](https://ffmpeg.org/download.html)。本机隔离工具也可使用[imageio-ffmpeg发行包](https://github.com/imageio/imageio-ffmpeg)，仅使用其附带的可执行文件；遵循对应发行包的许可证。该工具不是Java项目的Python依赖。

接口与原视频读取一样不允许公开缓存；原文件缺失、不可读、解码失败或未安装FFmpeg时返回业务错误，前端显示可重试提示，不以虚构封面代替成功。最多两个并行解码、12秒进程超时、480像素最长边、单图512KiB上限、64张内存LRU缓存。仅传入服务器生成的本地MP4临时路径并强制MOV/MP4解复用，不允许远程协议。每次结束清理输入及输出临时文件。
