# 本地批量待审核文章导入

`data/community/recommendation-articles-20261028.json` 包含18篇原创科普素材，覆盖饮食控糖、运动、日常管理、1型、2型和药物科普。每篇保留参考来源，供账号持有人明确授权后的本地演示数据准备使用。

`UserArticleBatchImport.java` 是独立运维工具，不属于应用请求处理路径，不在启动时运行。生产社区仍使用 MyBatis 和正常投稿限流；该工具通过一次性 JDBC 事务执行经过确认的本地导入，不开放 HTTP 接口。

## 使用步骤

1. 使用 Java 21 编译该文件，classpath 包含后端运行依赖（MySQL JDBC 驱动及 Jackson 3）。运行时使用相同 classpath 加上编译产物目录。
2. 确认工作区根 `.env` 指向本地开发库，核对账号ID及手机号。工具仅支持 `localhost` 或 `127.0.0.1`，不支持服务器库。
3. 从正在运行的后端进程到 MySQL 的 TCP 连接中，取得本地客户端端口；多个端口以逗号分隔。工具据此核对运行中后端实际连接的数据库，拒绝目标不一致的写入。
4. 先执行 `audit`，确认账号、18篇素材及六类启用标签有效；再将同一命令的模式改为 `apply`。

参数顺序：

```text
java -cp <运行依赖与工具类目录> UserArticleBatchImport
  audit|apply <工作区绝对路径> <确认的用户ID> <对应手机号> <素材JSON绝对路径> <运行后端的MySQL客户端端口列表>
```

这是参数示意，请按操作系统的命令续行方式输入，或合成一行执行。手机号及数据库配置仅在本机使用，不写入素材、仓库或共享日志。

## 数据与审核行为

- 导入前将涉及的六张业务表备份到工作区 `.tmp/user-article-batch-backup-*`，备份包含用户内容，不提交GitHub。
- 事务内锁定已确认的账号，并使用数据库命名锁防止同一工具并发导入；失败回滚。
- 写入 `cms_news`、作者关联、标签、可见性及提交审计；文章归入该用户“我的文章”，初始状态 `AI_PENDING`，`publish_status=0`。
- 原有审核队列执行AI初审，之后进入管理员终审；不伪造AI审核通过，不自动公开。只有实际审核发布、满足可见性条件的文章才参与公共推荐。
- 按素材种子键与账号ID防重复；相同内容再次执行会跳过，已存在但内容不同则拒绝覆盖。不会替换原有文章或修改存储桶。
- 属于显式批量数据准备，不改变普通用户投稿的每小时限额。
